## 🎨 DIRECTIVES ARTISTIQUES GÉNÉRALES

### Palette de couleurs
```css
--primary-blue: #228be6
--dark-blue: #0a0e27
--success-green: #40c057
--warning-orange: #ff922b
--background-light: #f8f9fa
--text-dark: #212529
--border-gray: #dee2e6
```

### Typographie
- **Titre principal** : Inter Bold, 42px
- **Sous-titres** : Inter SemiBold, 28px
- **Corps de texte** : Inter Regular, 18px
- **Petits textes** : Inter Regular, 14px

### Animations (timing)
- **Fade in/out** : 0.3s ease
- **Slide animations** : 0.4s ease-out
- **Bounce effects** : 0.5s cubic-bezier(0.68, -0.55, 0.265, 1.55)
- **Hover states** : 0.2s ease
- **Notifications** : 0.6s ease avec bounce

### Transitions entre scènes
- **Dissolve** : Fondu enchaîné (0.5s)
- **Zoom** : Zoom avant/arrière (0.6s)
- **Slide** : Glissement latéral (0.4s)
- **Wipe** : Balayage avec gradient (0.5s)
